Dutch Bros Android setup
  • 1Open Settings → About phone/tablet and tap Build number 7 times
  • 2Open Developer options and enable USB debugging
  • 3Connect a data-capable USB cable and unlock the device
  • 4Tap Allow on the USB debugging fingerprint prompt

If debugging is already on but the app says unauthorized: Developer options → Revoke USB debugging authorizations, toggle USB debugging off/on, reconnect, and tap Allow. Search Settings for “Build number” or “USB debugging” if the menu differs. Root access is not needed.
