A FEW STEPS, THEN YOU’RE CONNECTED

Make yourself at home.

First-time setup

  1. Run the Windows installer and follow its setup guide.
  2. Open chrome://extensions, enable Developer mode, and choose Load unpacked.
  3. Select %LOCALAPPDATA%\Programs\Reward Assist\browser-helper. An empty-looking folder picker is normal.
  4. Sign in on both devices. In Windows, open Phone connection and enable phone requests.
  5. On iPhone, open Computer sync → Start a computer task.

Updating an existing install

  1. Close Reward Assist on Windows, then run the new installer.
  2. In Chrome Extensions, reload Rewards Assistant Helper. Check that it says 0.5.45.
  3. Replace the iPhone app through your sideloading tool using the new IPA. Avoid deleting your wallet before updating.
  4. Cancel abandoned requests before starting a replacement. Cancellation cannot undo an account or order already submitted.

Android Wake Relay setup

  1. Download and install Reward-Assist-Wake-Relay.apk on an Android phone or tablet connected to home Wi-Fi.
  2. In Windows Reward Assist under Phone connection, copy your PC's Ethernet MAC address.
  3. On iPhone under Computer tasks → Wake from anywhere, select your PC and tap Create pairing key.
  4. In the Wake Relay app on Android, paste the pairing key and enter your PC's MAC address, then tap Enable wake relay.
  5. Keep the Android device charged and connected to home Wi-Fi. You can now tap Wake Computer from cellular data anytime.

Android device setup (Automated apps)

  1. Enable Developer options: in Android Settings → About phone, tap Build number 7 times.
  2. Open Developer options and toggle USB debugging ON.
  3. Connect phone to PC with USB. On the prompt, check Always allow from this computer and tap Allow.
  4. Set screen lock to Swipe or None (or enable Stay awake while charging in Developer options).

Wireless PC wake (Wi-Fi)

  1. In Device Manager → Network adapters → right-click your Wi-Fi card → Properties → Power Management: check Allow this device to wake the computer.
  2. In Advanced tab: enable Wake on Magic Packet and WoWLAN.
  3. Disable Windows Fast Startup in Control Panel → Power Options.
  4. Enable PCIe / Wake on LAN in your motherboard BIOS.

Remote power (Smart plug)

  1. Plug your PC into a $10 smart plug (e.g. Kasa or Tapo).
  2. In MSI BIOS, set Restore after AC Power Loss to Power On.
  3. Turn on the smart plug from cellular anytime to boot your PC immediately.
  4. In the iPhone app under Computer Sync, tap the title 5 times if you want advanced Wake-on-LAN controls.
