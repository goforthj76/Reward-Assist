A CLEAR NEXT STEP

New here, or coming back?

The extension files come with setup. Chrome asks you to enable them once.

01 / FIRST INSTALL

Enable the Chrome helper

  1. In Chrome, open chrome://extensions.
  2. Turn on Developer mode, then choose Load unpacked.
  3. Paste this into the folder picker's address bar and press Enter:%LOCALAPPDATA%\Programs\Reward Assist\browser-helper
  4. Click Select Folder. An empty-looking folder picker is normal: it only displays folders.
  5. Confirm Rewards Assistant Helper 0.5.34 is enabled.
02 / UPDATING

Already have Reward Assist?

  1. Close all Reward Assist windows and run the new installer.
  2. Open chrome://extensions and click the helper's Reload ↻ button.
  3. Check that its version says 0.5.34, then refresh the restaurant tab.
  4. If the version stays old, remove only Rewards Assistant Helper and load the folder shown in the first-install guide. Reloading an old folder does not update its files.
